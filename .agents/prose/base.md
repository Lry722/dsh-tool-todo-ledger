# Rules

1. 严禁把一段话写得太长，把前后关系梳理清楚，局部只专注于一个话题。但也不能把完整的内容拆太碎，控制合适的段落长度。
2. 注意保持平铺直叙的风格，严禁滥用括号和长难句。
3. 严禁滥用否定句，例如 “不影响”、“不进入”、“不是…而是…” 这类说法。
4. 严禁滥用形容词，例如 “可读”、“可审查”、“天然” 这类词。
5. 合理断句，严禁滥用逗号和句号外的符号，例如分号、破折号。
6. 相似的概念和动作应当用相同的术语表述，提高一致性，降低理解负担。
7. 适当口语化，严禁为了追求简洁而使用过于简短的词汇。
8. 英文俚语应当翻译地道，避免翻译腔，例如强行直译。如果很难翻译，就保留英文原文。
9.  对于过程性描述，应当将其自然融入整体。不要和废弃的内容做对比，只保留现状。

# 说明

滥用是指频次过高和非必要使用，也就是存在更好的表达方案。若修改后没有明显更好，则不用强行修改。
